# Maven Dependency Graph — вариант №9

## Описание проекта

Программа анализирует зависимости Java-пакетов Maven
и строит граф зависимостей.

Реализована на Python с использованием стандартной
библиотеки.

## Возможности

- Обработка аргументов командной строки.
- Загрузка Maven POM из репозитория.
- Определение прямых зависимостей.
- Построение транзитивного графа.
- Итеративный обход DFS без рекурсии.
- Обработка циклических зависимостей.
- Работа с тестовыми TXT-репозиториями.
- Поиск обратных зависимостей.
- Создание диаграмм PlantUML.
- Экспорт диаграмм в SVG.
- Вывод ASCII-дерева.

## Структура проекта

src/ — исходный код приложения.

tests/ — автоматические тесты.

tests/data/ — тестовые репозитории.

tools/ — PlantUML JAR.

output/ — результаты визуализации.

run.bat — запуск основного примера.

demo.bat — демонстрация трёх графов.

test.bat — запуск всех тестов.

## Настройки

--package — имя анализируемого пакета.

--repo — URL Maven-репозитория или путь к TXT.

--test — использование тестового репозитория.

--version — версия Maven-пакета.

--output — имя SVG-файла.

--ascii — вывод ASCII-дерева.

--reverse — поиск обратных зависимостей.

## Требования

Python 3.11 или новее.

Java для запуска PlantUML.

Файл tools/plantuml.jar.

## Установка

1. Открыть проект в PyCharm.
2. Проверить наличие Python.
3. Установить Java.
4. Скачать PlantUML JAR.
5. Поместить его в tools/plantuml.jar.

## Запуск

Для основного примера открыть run.bat.

Для демонстрации трёх пакетов открыть demo.bat.

Для автоматического тестирования открыть test.bat.

## Пример анализа тестового репозитория

python -m src.main --package A --repo tests/data/normal.txt --test --output graph.svg --ascii

## Пример анализа Maven

python -m src.main --package org.slf4j:slf4j-api --repo https://repo.maven.apache.org/maven2 --version 2.0.13 --output maven.svg --ascii

## Обратные зависимости

python -m src.main --package F --repo tests/data/normal.txt --test --reverse

## Тестовые репозитории

normal.txt — обычный граф зависимостей.

cycle.txt — граф с циклическими зависимостями.

empty.txt — граф без зависимостей.

## Визуализация

Файлы .puml содержат описание диаграммы PlantUML.

Файлы .svg содержат готовые изображения.

Все результаты сохраняются в папке output/.

## Сравнение с Maven

Для штатного анализа используется Maven Dependency Plugin
с целью dependency:tree.

Разработанная программа строит собственный граф
на основании прочитанных POM-файлов.

Возможны различия из-за:

- dependencyManagement;
- parent POM;
- BOM;
- разрешения конфликтов версий;
- исключений зависимостей;
- профилей Maven;
- областей видимости зависимостей.

Сравнение необходимо выполнять на одинаковых
версиях зависимостей.

## Ограничения

Программа не реализует полный механизм
разрешения зависимостей Maven.

Обратные зависимости реального Maven-пакета
ищутся только в уже построенном графе.

## Этапы разработки

1. CLI и обработка параметров.
2. Получение прямых зависимостей Maven.
3. Итеративный DFS и транзитивный граф.
4. Поиск обратных зависимостей.
5. PlantUML, SVG и ASCII-дерево.
