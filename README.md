# Maven Dependency Graph — вариант 9

## Описание

Программа анализирует зависимости Maven-пакетов
и строит граф с учётом транзитивных зависимостей.

Этап 3: DFS без рекурсии и тестовые репозитории.

## Настройки

- `--package` — анализируемый пакет.
- `--repo` — URL Maven или путь к TXT-файлу.
- `--test` — включение тестового режима.
- `--version` — версия Maven-пакета.
- `--output` — имя будущего SVG.
- `--ascii` — режим будущего ASCII-дерева.

## Функции

### config.py
Чтение и проверка параметров CLI.

### maven.py
Загрузка POM и получение прямых зависимостей.

### test_repo.py
`read_test_repo()` — чтение тестового графа.

### graph.py
- `build_graph()` — обход DFS без рекурсии.
- `graph_edges()` — получение рёбер графа.

### main.py
- `make_provider()` — выбор источника зависимостей.
- `main()` — построение и вывод графа.

## Тестовые данные

Формат TXT:

A: B C
B: D
C:
D:

Каждая строка описывает пакет и его зависимости.

- normal.txt — обычный граф.
- cycle.txt — граф с циклом.
- empty.txt — граф без зависимостей.

## Запуск

`run.bat` — запуск программы.

`test.bat` — запуск автоматических тестов.

Сборка не требуется. Используется Python 3.11+.

## Примеры

Тестовый режим:

python -m src.main --package A --repo tests/data/normal.txt --test

Maven:

python -m src.main --package org.slf4j:slf4j-api --repo https://repo.maven.apache.org/maven2 --version 2.0.13

## Ограничения

Maven POM обрабатывается упрощённо.
Полное разрешение parent, BOM и dependencyManagement
не реализовано. В реальном Maven граф может отличаться.

Режим обратных зависимостей появится на этапе 4.
Визуализация появится на этапе 5.
