# Maven Dependency Graph — вариант 9

Практическая работа №2. Анализ зависимостей Maven.

## Описание

Программа получает прямые зависимости Maven-пакета
из удалённого репозитория по указанной версии.

Используется стандартная библиотека Python.

## Параметры

- `--package` — пакет group:artifact.
- `--repo` — URL Maven-репозитория.
- `--version` — версия пакета.
- `--test` — тестовый режим (реализация на этапе 3).
- `--output` — имя SVG-файла.
- `--ascii` — вывод ASCII-дерева (этап 5).

## Функции

### config.py

Проверка имени пакета, версии, файла и параметров.

### maven.py

- `pom_url()` — формирует адрес POM.
- `download_pom()` — загружает POM.
- `child_text()` — читает XML-элемент.
- `get_properties()` — читает свойства проекта.
- `resolve()` — заменяет простые переменные.
- `parse_pom()` — извлекает прямые зависимости.
- `get_dependencies()` — объединяет загрузку и разбор.

### main.py

`main()` — выводит прямые зависимости.

## Запуск и тестирование

Запуск программы: `run.bat`.

Запуск тестов: `test.bat`.

Сборка не требуется. Достаточно Python 3.11+.

## Пример

python -m src.main --package org.slf4j:slf4j-api --repo https://repo.maven.apache.org/maven2 --version 2.0.13

## Ограничения

Программа пока не строит транзитивный граф.

Поддерживаются явные версии и простые свойства POM.
Полная модель разрешения зависимостей Maven,
включая parent, BOM и dependencyManagement,
не реализована.
