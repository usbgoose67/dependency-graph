# Maven Dependency Graph — вариант 9

## Описание

Приложение для анализа прямых, транзитивных
и обратных зависимостей пакетов Maven.

Этап 4: поиск обратных зависимостей.

## Настройки

- `--package` — имя пакета.
- `--repo` — URL Maven или путь к TXT.
- `--test` — тестовый режим.
- `--version` — версия Maven-пакета.
- `--output` — имя SVG-файла.
- `--ascii` — режим ASCII-дерева.
- `--reverse` — поиск обратных зависимостей.

## Функции

### config.py
Проверка аргументов командной строки.

### maven.py
Загрузка и разбор Maven POM.

### test_repo.py
Чтение тестового графа из TXT.

### graph.py
- `build_graph()` — итеративный DFS.
- `graph_edges()` — получение рёбер.
- `reverse_graph()` — обращение направлений рёбер.
- `find_reverse_dependencies()` — обратный DFS.

### main.py
Выбор режима работы и вывод результата.

## Тестовые данные

- `normal.txt` — обычный граф.
- `cycle.txt` — циклический граф.
- `empty.txt` — изолированные пакеты.

Формат строки: A: B C

## Запуск и тесты

Запуск: `run.bat`.

Тестирование: `test.bat`.

Python 3.11+, установка библиотек не требуется.

## Примеры

Прямой анализ:

python -m src.main --package A --repo tests/data/normal.txt --test

Обратный анализ:

python -m src.main --package F --repo tests/data/normal.txt --test --reverse

## Ограничения

В Maven-режиме поддерживается упрощённый POM.
Глобальные обратные зависимости Maven недоступны:
для этого нужен индекс всего репозитория.

Визуализация будет добавлена на этапе 5.
