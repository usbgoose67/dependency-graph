# Maven Dependency Graph — вариант 9

Практическая работа №2 по конфигурационному управлению.

## Описание

Консольное приложение на Python для анализа зависимостей
пакетов Maven.

Этап 1: обработка параметров командной строки.

## Параметры

- `--package` — имя пакета, обязательный параметр.
- `--repo` — URL репозитория или путь к TXT-файлу.
- `--test` — включить тестовый режим.
- `--version` — версия пакета, по умолчанию 1.0.
- `--output` — имя SVG-файла, по умолчанию graph.svg.
- `--ascii` — включить ASCII-дерево.

## Функции

- `package_name()` — проверка имени пакета.
- `version_name()` — проверка версии.
- `output_name()` — проверка имени изображения.
- `make_parser()` — создание аргументов.
- `read_config()` — проверка настроек.
- `main()` — вывод настроек.

## Запуск

Запустить `run.bat`.

Для запуска тестов использовать `test.bat`.

Установка сторонних библиотек не требуется.

## Пример

python -m src.main --package org.slf4j:slf4j-api --repo https://repo.maven.apache.org/maven2 --version 2.0.13

Программа выводит параметры в формате ключ-значение.
